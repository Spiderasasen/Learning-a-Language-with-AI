# Learning-a-Language-with-AI
A project that will be used to help answer a question. Can AI be used to help others learn a language?

# The main purpose is simple
The idea is for people to learn a new language. But most places that require you to learn with AI are behind a paywall.
But does it actually work?

In this project, I'll be answering that question with some ways that help me learn my languages.

- drilling
- practice

# drilling #
It's not that hard, but it is needed.
If you don't know a word, you can repeat it as many times as you need.
even if you need to write it or hear it and then write it. It's a very necessary process that can help us in the future

# practice #
Now it's common knowledge that if you don't practice, you don't get better. So that is what we need to do as well.
Practice talking to an AI, via writing or speaking to it.
In this research, since most of our audience are people minoring or majoring in a language, we won't need that much speaking practice. 
*depends on what my teacher says*
But writing is going to be needed for practice.
Luckily, the little bit of practice that i have, AI goes based on the language you write in it. 
So if i can just lock the language behind a simple version of the language being practiced, it can help the student learn writing and reading the language.
