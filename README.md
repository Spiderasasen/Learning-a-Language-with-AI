# Learning-a-Language-with-AI
A project that will be used to help answer a question. can AI be used to help others learn a language?

# The main purpose is simple
the idea is for people to learn a new language. but most places that require you to learn with AI, is behind a price wall.
But does it actually work?

In this project I'll be answering that question with some ways that help me learn my languages.

- drilling
- practice

# drilling #
its not that hard, but it is needed.
if you don't know a word, you can repeat it as many times as you need.
even if you need to write it or hear it and then write it. its a very needed process that can help us in the future

# practice #
Now its common knowledge that if you don't practice, you don't get better. so that is what we need to do as well.
practice talking to an AI, via writing or speaking to it.
in this research since most of our audience are people minoring or majoring into a language, we wont need that much speaking practice
*depends on what my teacher says*
but writing is going to be needed for practice.
lucky the little bit of practice that i have, AI goes based on the language you write in it. 
so if i can just lock the language behind a simple version of the language being practiced, it can help the student learn writing and reading the language.
